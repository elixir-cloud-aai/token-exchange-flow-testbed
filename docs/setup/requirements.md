# Requirements

**For the mock:** Docker with Compose, on Linux, macOS or WSL. It has been run on Linux only so far. No Python on your machine, no free ports, no account.

**For LS Login, also:**

- Two test accounts and five registered clients: see [Client registration](client-registration.md).
- A browser on the same machine. Otherwise see [Remote machines](remote.md).
- Port 18994 free on your machine's loopback interface, for the login callback.

No public hosting is involved: LS Login only sees your browser and the testbed's outgoing requests.
